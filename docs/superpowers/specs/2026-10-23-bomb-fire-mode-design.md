# v1.5.0 娱乐模式·无限火力 — 设计文档

日期：2026-10-23　状态：已实现

## 背景与目标

在「娱乐模式」容器内新增第三个玩法 **无限火力**：

- **军旗、工兵、地雷全部换成炸弹**：每方 9 颗炸弹 + 16 枚普通军衔子，仍为 25 子。
- **胜利条件：消灭对方全部棋子**（棋盘上不再有对方棋子，无论明暗）。
- 保留翻翻棋的核心体验：开局随机背面朝下、首翻定阵营，经典模式 / 军衔升级 / 镜像明棋行为不变。

非目标：新增棋子类型、改变地形（铁路/行营/楚河）与普通子交战规则。

## 核心架构决策

### ① variant 扩展

`constants.VARIANTS` 新增 `BOMB_FIRE: 'bombFire'`，与 `mode`（人机/双人）正交。
variant 仍是纯数据字段，随 `createInitialState({mode, variant})` 写入 state，
经 JSON 快照自动进入 AI Worker / 悔棋快照。

### ② 棋子构成数据化（constants.pieceCounts）

原先 `state.buildPieces`、`ai.remainingDistribution`、`ui.trackerData` 三处都直接读
`PIECES[type].count`。无限火力下这些计数不再成立，因此新增：

```js
BASE_COUNTS      // 经典/军衔升级/镜像明棋（由 PIECES 表生成）
BOMB_FIRE_COUNTS // { commander:1, general:1, division:2, brigade:2,
                 //   regiment:2, battalion:2, company:3, platoon:3, bomb:9 }
pieceCounts(variant) // 返回对应构成
```

换算：军旗 1 + 工兵 3 + 地雷 3 = 7 枚特殊子并入原有 2 枚炸弹 → **9 炸弹**；
普通军衔子 1+1+2+2+2+2+3+3 = 16 枚，合计仍为 25 枚/方。

发牌沿用经典随机铺子逻辑（本次不镜像），因此 `buildPieces(variant)` 只在构成上分化。

### ③ 胜负判定（rules.checkWinner）

在既有「困毙判负 / 40 回合判和」之前增加无限火力终局：

```js
if (state.variant === 'bombFire') {
  // 统计双方棋盘上现存棋子数
  if (!red && !blue) return 'draw';   // 最后一击同归于尽
  if (!red) return 'blue';
  if (!blue) return 'red';
}
```

**必须先于「无路可走」判定**：全军覆没的一方必然也没有合法行动，
若沿用旧顺序会被误判为普通困毙（结果同为对方胜，但双亡时会错判一方胜而非和局）。
困毙与 40 回合无吃翻判和作为次要终局保留。

### ④ 规则/AI 的其余部分天然兼容

- `resolveBattle` 的炸弹分支（任一方为炸弹即同归）无需修改；地雷/军旗分支永不命中。
- `IMMOBILE`（地雷/军旗）在无限火力中无对应棋子；所有子均可移动。
- 军旗保护（拔满 3 雷才可攻旗）与司令阵亡亮旗逻辑均因场上无旗/雷而成为 no-op。
- AI 的 `remainingDistribution` 改为按 `pieceCounts` 初始化，翻棋 chance 采样自动得到
  9 炸弹的正确概率；估值/搜索/置换表沿用既有逻辑。
- `clone` 已携带 variant，make/unmake 与快照一致性契约不受影响。

### ⑤ UI

- 开局弹窗新增「娱乐·无限火力」；顶栏金标与规则弹窗附条同步。
- 左栏「未翻透视」照常工作（本玩法仍有暗子），但隐藏无意义的**拔雷进度条**，
  改为显示玩法说明。
- 记牌器只为本玩法存在的棋子建 chip（9 炸弹 + 16 普通子），未翻计数/阵亡名册口径一致。
- 终局浮层副标题：败方无子 → 「对方全军覆没」；仍有子但被封锁 → 「对方无路可走」。

## 测试

新增 `tests/bombfire.test.js`（9 项）：

- 每方构成 9 炸弹 + 16 普通子、无军旗/工兵/地雷、共 50 枚暗子；
- 消灭对方最后一子获胜 / 攻方全灭判负 / 双方同归于尽判和；
- 炸弹同归且双方仍有子时不终局；
- 无雷时军旗保护不参与（任意子可被攻击）；
- AI 剩余分布为 9 炸弹且不含特殊子；
- AI 中档返回合法动作且不篡改局面；
- 记牌器口径与阵亡扣减。

全量 `npm test`：186 项通过。

## 已知取舍

- 9 枚炸弹/方使炸弹成为主战兵种，普通军衔子的相对价值下降；AI 仍沿用
  `PIECE_VALUE.bomb = 35` 的经典估值，未针对本玩法单独调参（后续可做 A/B）。
- 40 回合无吃翻判和沿用经典阈值；若实战节奏偏拖，可在后续版本为 `bombFire`
  单独放宽 `STALE_LIMIT`。
